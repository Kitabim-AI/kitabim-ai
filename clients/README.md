# clients

## Overview
Standalone client applications and external tools that interact with the Kitabim platform over public HTTP APIs. These clients execute outside the containerized service cluster on user or client hardware.

## Subdirectories & Boundaries
- [kitabim-ocr](./kitabim-ocr/README.md) - Standalone desktop OCR application running local Surya OCR inference with browser-based review and API synchronization.
