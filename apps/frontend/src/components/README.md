# Components Blueprint (`apps/frontend/src/components`)

## Overview
Presentation, interaction, and container components for the Kitabim.AI frontend application, grouping modular UI subsystems for book reading, library management, conversational AI research, knowledge graph exploration, orthographic spell-checking, administration, and shared layout primitives.

## Subdirectories & Boundaries
- `admin`: [./admin/README.md](./admin/README.md) - Administrative management console, book pipeline monitoring, user management, and dictionary administration.
- `auth`: [./auth/README.md](./auth/README.md) - Authentication controls, OAuth provider buttons, and user profile navigation menu.
- `chat`: [./chat/README.md](./chat/README.md) - Conversational AI interface, multi-step agent reasoning visualization, and citation reference modal.
- `common`: [./common/README.md](./common/README.md) - Reusable UI components including modal dialogs, markdown rendering, notifications, and localized text displays.
- `graph`: [./graph/README.md](./graph/README.md) - Interactive 2D force-directed knowledge graph visualization and entity curation tools.
- `layout`: [./layout/README.md](./layout/README.md) - Application shell framing, top navigation bar, theme switching, and global footer.
- `library`: [./library/README.md](./library/README.md) - Bookshelf catalogue, multi-tab search experience, virtual keyboard, reading history, and bookmarks.
- `pages`: [./pages/README.md](./pages/README.md) - Top-level route views for trilingual Quran reader, dictionary suite, and volunteer landing page.
- `reader`: [./reader/README.md](./reader/README.md) - Virtualized book reader workspace, inline text correction, OCR diff highlights, and bookmarking.
- `share`: [./share/README.md](./share/README.md) - Social media and clipboard sharing modals for books, search passages, and Q&A interactions.
- `spell-check`: [./spell-check/README.md](./spell-check/README.md) - Interactive orthographic spell-checking view, suggestion overlays, and review queue.
- `ui`: [./ui/README.md](./ui/README.md) - Base visual design primitives including glassmorphic panels.
