# Packages (`packages`)

## Overview
Shared libraries and type contract packages consumed across Kitabim.AI services, applications, and client tools.

## Subdirectories & Boundaries
- [backend-core](./backend-core/README.md) - Core backend Python package providing database persistence (SQLAlchemy 2.0), Gemini LLM integrations, RAG pipelines, worker jobs, and utilities.
- [shared](./shared/README.md) - Shared TypeScript types, data contracts, and OpenAPI definitions consumed across the frontend and API clients.
